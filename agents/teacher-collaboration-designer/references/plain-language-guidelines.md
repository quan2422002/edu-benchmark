# Plain-language guidelines

- Write teacher-facing text in natural Vietnamese by default.
- Use English only for proper names, file/field identifiers, tool names, or technical terms that are clearer in English.
- Explain any unavoidable English term in Vietnamese on first meaningful use.
- Start instructions with an action verb.
- Keep one main action per sentence.
- Prefer Vietnamese educational terms familiar to teachers.
- Replace technical storage terms with task language; do not show the replaced term to teachers.
- State what to submit and where to submit it.
- Provide an estimated completion time.
- Show a complete example and a counterexample.
- Explain why the counterexample is problematic.
- Distinguish required fields from optional fields.
- Treat questions and confusion as useful pilot outputs.

Do not mention implementation tools or data formats in teacher-facing text, including statements that say teachers are not expected to use them. State only the familiar action the teacher should perform.
