# Rubric and serious-error guidelines

Use this file when drafting rubric dimensions or serious-error catalogs.

## Rubric rules

- A rubric should measure observable tutor behavior or response quality.
- A rubric should name what a reviewer can inspect in the response or dialogue.
- Do not infer learning gains from response quality unless the evidence supports that claim.
- Link each rubric to at least one task.
- Mark unconfirmed pedagogical expectations as `needs_hnmu_review`.

## Serious-error rules

A serious error should describe a failure that may invalidate or strongly cap a tutor response, such as:

- unsafe or harmful guidance;
- confidently wrong subject-matter instruction;
- bypassing the student’s learning process when scaffolding is required;
- ignoring clear prerequisite gaps;
- fabricating curriculum or source references.

For each serious error, state:

- `error_id`;
- description;
- suggested action;
- affected rubric IDs;
- status and confirmation owner.

Suggested actions are provisional until HNMU confirms them.
