# Pointer tới học liệu dùng chung

Không copy học liệu vào experiment này vì học liệu SGK/SGV là tài nguyên dùng chung của toàn dự án.

Khi giai đoạn 2 cần kiểm học liệu, dùng các nguồn sau:

| Mục đích | Đường dẫn |
|---|---|
| Tra cứu fragment SGK/SGV | `shared/learning_resources/fragments/learning_resource_fragments.csv` |
| Full-text search SQLite | `shared/learning_resources/indexes/learning_resources_v0.sqlite` |
| Manifest OCR SGK/SGV | `shared/learning_resources/registries/ocr_text_manifest.csv` |
| Map chủ đề/bài học THCS | `shared/learning_resources/registries/sgk_thcs_topic_lesson_map_v0.csv` |
| Hướng dẫn agent truy xuất học liệu | `shared/learning_resources/agent_context/README.md` |
| Phương pháp dàn giáo HNMU | `shared/learning_resources/agent_context/hnmu_scaffolding_method_canonical.md` |
| Mức nhận thức HNMU | `shared/learning_resources/agent_context/hnmu_cognitive_level_method_canonical.md` |

Nếu cần snapshot học liệu cho một báo cáo hoặc bản nộp cụ thể, hãy tạo một plan riêng để tránh copy nhầm file nặng vào experiment.
